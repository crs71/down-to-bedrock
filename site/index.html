How this site was made

  • Scroll-driven CSS

    The sunset, the sinking sun and the drifting clouds are plain CSS, tied to the page scroll with animation-timeline. Browsers without it get a complete static version.

  • Pinned scenes with GSAP

    The surface, the minecart ride and the Nether use GSAP ScrollTrigger: the scene stays put while the world slides sideways, and the creeper explodes once, in real time.

  • Pixel art written as text

    Every sprite is a grid of characters, turned into SVG by a PowerShell script. Colors come from CSS variables, so the whole page changes palette from one place. That is how the portal works.

  • Accessible from the start

    With “reduce motion” turned on in your system, the page becomes static. Headings stay real text, the Nether mobs are real buttons, and animations only use transform and opacity.
