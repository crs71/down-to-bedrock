Cum e făcut site-ul

  • Animații CSS legate de scroll

    Cerul, soarele, norii și fisurile din piatră se mișcă doar din CSS, cu animation-timeline. Browserele care nu îl suportă primesc o variantă statică, completă.

  • Scene fixate cu GSAP

    Suprafața folosește GSAP ScrollTrigger: secțiunea se fixează, peisajul merge orizontal, iar explozia pornește o singură dată, în timp real.

  • Pixel art scris ca text

    Fiecare sprite e o grilă de caractere, transformată în SVG de un script PowerShell. Culorile vin din variabile CSS, deci paleta întregii pagini se schimbă dintr-un singur loc.

  • Accesibil din start

    Cu „reducerea mișcării” activată în sistem, pagina devine statică. Titlurile rămân text real, iar animațiile folosesc doar transform și opacity.
